# 真机验收清单

## 准备

- [ ] Android Studio 编译安装 debug APK 到真机
- [ ] 拼多多已登录，能手动搜「安宫牛黄丸」
- [ ] 已开启「拼多多采集助手」无障碍
- [ ] （推荐）忽略电池优化

## 用例 A：综合 N=2

1. 关键词：`安宫牛黄丸`
2. N = 2
3. 价格/销量开关：**关**
4. 点开始，等待结束

期望：

- [ ] 日志出现 `任务启动`、`已搜索：安宫牛黄丸`、`综合排序，采集前 2 个`
- [ ] 至少 1 条 `成功【default_top_x】`，且准字/规格/展示价至少有一项非空
- [ ] 导出 CSV 可打开，含「详情展示价」「店铺销量」「多规格价格」等列

## 用例 B：排序开关冒烟

1. 同一关键词，N = 1
2. 打开「价格排序第1个」「销量排序第1个」
3. 开始

期望：

- [ ] 日志出现 `价格升序` / `销量降序` 相关行
- [ ] 出现 `pick_tag` 对应成功或失败日志，**App 不崩溃**
- [ ] 停止按钮可中断后续关键词
